# report-review — HTMLレポートのレビュー/推敲・音声入力・ローカル保存レイヤ（汎用）

任意の自己完結HTMLレポートに、**ブラウザ上での編集・コメント・音声入力・保存**の仕組みを後付けする Kyberion 汎用ツール。特定レポートに埋め込むのではなく、**どのレポートにも同じ体験を横展開**する。

外部リソース読込ゼロ（すべてインライン）＝CSP/機密運用に安全。ファイルI/Oは `@agent/core/secure-io` 経由。

## 構成

| ファイル          | 役割                                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `review-layer.ts` | レビューレイヤ本体（CSS+JS）の**単一正本**。server/stamp が共用。`reviewLayerMarkup()` を export                         |
| `server.ts`       | **方式B**：任意HTMLを 127.0.0.1 で配信し、配信時にレイヤをオーバーレイ注入。💾でファイルへ直書き保存（バックアップ付き） |
| `stamp.ts`        | **方式A**：レイヤをファイルへ焼き込む/剥がす（`file://` オフライン用）                                                   |

## 機能（レビューレイヤ）

- ✏️ 編集：本文を直接書き換え（localStorage 自動保存）
- 💬 コメント：選択テキストに注釈。入力は **キーボード / OSディクテーション（端末内・推奨） / 🎤ブラウザ音声認識**
- 🗂 一覧 ／ ↺ 復元 ／ ⤓ HTML書出し ／ ⤓ コメントMD ／ 🗑 破棄
- 💾 保存(直書き)：サーバ経由時のみ表示（方式B）

## 使い方

### 方式B（推奨・往復編集 / 🎤も使える）

```bash
KYBERION_PERSONA=sovereign node_modules/.bin/tsx scripts/report-review/server.ts <report.html> [port]
# → http://127.0.0.1:<port>/ を開く（localhost=セキュアコンテキストなので 🎤 マイク可）
```

- 保存先は起動時の1ファイルに固定・127.0.0.1限定・トークン＋Origin検査。
- 配信時に注入したレイヤ/configは保存時に自動除去（正本はコンテンツのみのクリーンな状態を維持）。
- 既にレイヤが焼き込まれたレポートには再注入しない（二重表示防止）。

### 方式A（サーバ不要・オフライン / `file://`）

```bash
node_modules/.bin/tsx scripts/report-review/stamp.ts <report.html>          # 焼き込む
node_modules/.bin/tsx scripts/report-review/stamp.ts <report.html> --remove # 剥がす
```

`file://` で開いて編集・コメント・エクスポート。※`file://` は 🎤(Web Speech) がマイク制限で使えないことが多い（OSディクテーションは可）。

## AIによるレビュー反映ループ

1. ブラウザで ✏️編集／💬コメント（＝修正指示）→ 💾保存（方式B）または ⤓書出し（方式A）
2. AIに「反映して」と指示
3. AIが `mark.rv-cmt` の `data-note`（コメント）と本文の直接編集を汲み取り、本文へ反映 → 注釈除去 → 対応ログ提示

## セキュリティ/機密の注意

- 🎤（Web Speech API）は機種により**音声がブラウザ提供元のクラウドへ送信**される。機微な内容は **OSディクテーション（端末内）** を使うこと。
- confidential 階層のレポートを保存する場合、secure-io のティアガードにより適切な `KYBERION_PERSONA` が必要。
- 生成されるバックアップ `<file>.bak-<ts>` は元ファイルと同じ階層に残る（不要なら削除）。
