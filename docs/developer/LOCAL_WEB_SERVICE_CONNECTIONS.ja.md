# 自分の PC から外部サービスを登録する

自分の PC の Concierge から GitHub と Slack の既存アクセストークンを登録し、読み取り専用で認証を確認する。提供元でのアカウント・アプリ作成、トークン発行は代行しない。

## 開き方と手順

ビルド後、リポジトリのルートから pnpm --dir presence/displays/concierge local:start を実行し、http://127.0.0.1:3050/settings#setup-services を開く。開発時は同じディレクトリ指定で local:dev を使える。通常の surface runtime もローカル専用アダプターを使う。

既存の start / dev は従来のリモート認証用として残る。共有認証情報の登録・閲覧・OAuth 開始は、その起動経路からは許可されない。ローカル用リスナーをトンネルやリバースプロキシで外部へ公開しない。

1. 提供元リンクで、必要最小限の権限を持つトークンを自分で発行する。
2. 登録準備を選び、対象サービスと保存先を確認する。承認待ちの場合は同じ申請の「承認状態を確認」を使う。
3. 専用入力欄へトークンを入力して保存する。送信時に欄を消去し、React 状態やブラウザー保存領域には保持しない。
4. 保存成功後、同じ実行用接続で認証を確認する。後から再確認もできる。
5. 依頼画面で「GitHub の登録済み接続でリポジトリ一覧を取得して」などのサービス処理を依頼する。

「利用する」選択は初期設定のメタデータで、登録とは独立している。選択を外しても切断・トークン失効は行わない。プロフィールやサービス選択の保存は既存接続ファイルを変更しない。

## 状態の意味

- 未登録: この登録経路のローカル接続値がない。
- 登録済み・未確認: 保存済み。認証成功とは区別する。
- 認証確認済み: GitHub の利用者確認、または Slack auth.test が成功した。
- 別の認証情報が優先: 環境変数や外部保管先が登録値より優先されている。自動上書きしない。
- 復旧が必要: キーチェーンと接続ファイルの保存が部分的に完了した可能性がある。自動再試行しない。

認証確認は、全リポジトリ・チャンネルへのアクセス、書き込み権限、Slack Socket Mode の利用まで保証しない。再読み込み後は保存状態を表示し、古い確認結果を成功表示に再利用しない。

## 通常のタスクで使う経路

登録値は既存の service:preset / service-actuator PRESET が使う接続へ保存される。タスクでは auth: secret-guard を明示する。GitHub list_repos、Slack conversations_history などの REST プリセットが対象。

登録だけでミッションの利用権限は増えない。通常のミッション認可を別途通し、未許可なら停止する。提供元のトークン権限・対象リポジトリ・チャンネル所属を越えることはできない。

既存の daily-github-inbox テンプレートは登録接続を明示した REST プリセットを使う。GitHub CLI の vcs ヘルパーや gh ベースの別テンプレート、Slack gateway の APP_TOKEN・Socket Mode は別系統。この登録だけで準備完了とは扱わない。既に動く別プロセスが古い接続をキャッシュしている場合、そのプロセスの再起動が必要な場合がある。

## 保存と安全境界

既存の OS キーチェーン・ローカル接続保存ポリシーに従う。暗号化は既存設定に依存し、初期状態で必ず暗号化されるわけではない。この経路で書く接続ファイルとバックアップは所有者のみ読み書きできるモードを用いる。

申請を操作者・サービス・キー・期限に結びつけ、保存前に耐久的な一回限りの適用記録を作る。並行処理や中断後の再送を防ぎ、障害時に値や提供元の生エラーを返さない。

起動アダプターは TCP 接続元と Host を確認し、クライアントの転送・証明ヘッダーを信用しない。登録 API、既存秘密値 API、OAuth 開始 API は同じ境界で保護する。複数利用者サーバーへの開放には、利用者別保管と実行時接続分離が別途必要。

## 対象外と検証

Google Workspace / Microsoft 365 / Notion の Web OAuth、提供元での権限追加・発行・失効、CLI や gateway の自動設定変更、実アカウントでの認証試験、リモート運用への展開は対象外。

検証は合成トークンとモック通信で行う。実アカウントを設定するときは、利用者が提供元の権限と保存先を確認して操作する。
