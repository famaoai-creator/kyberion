# Orphan decisions — libs/core (OW-01 / OW-02), 2026-10-01

Scope: COHERENCE_AUDIT_PLAN_2026-10-01 items OW-01 (subsystems) and OW-02 (modules). Each
candidate was re-checked on this tree with a symbol grep over the repo, excluding tests, `dist/`,
`retired/`, docs and the `libs/core` barrels (`grep -a`, two files contain NUL bytes).

Policy applied: **wire** when a production call site exists whose design clearly anticipates the
feature, behind a default-off flag when behaviour changes; otherwise **retire** (`git mv` to
`retired/libs-core/<path>` with its tests, barrel exports and `libs/core/package.json` subpaths
removed, row in [`retired/README.md`](../../../retired/README.md)). Two further outcomes appear
below: **keep** — re-checking showed the candidate is not orphaned — and **hand off** — the
natural call site exists but sits in code owned by another work item (`scripts/**`,
`pipelines/**`, actuator ops), so the wiring belongs there.

## Wave 3 — baseline triage (2026-10-01)

Every OW-07 baseline entry (44 libs/core modules, 1 script, 14 pipelines, 184 actuator ops) got a

### Checker rules (scripts/check_orphans.ts)

| Rule                           | Why                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agent-callable op              | An op is reachable when it is advertised in `actuator-op-discovery.json` (rendered into `CAPABILITIES_GUIDE.md`, which AGENTS.md and the subagent prompt framing point agents to for LLM-authored ADF) **and** a unit test names it (quoted in its own actuator's tests, or `domain:op` in any test under `libs/`, `scripts/` or `tests/`). Advertised-but-untested and tested-but-unadvertised ops stay orphans. |
| Provider-bridge op             | `codex:*` / `gh:*` ops are reachable when the pipeline provider bridge resolves them to a `cli_native` harness capability (`harness-capabilities/*.json`), mirroring `resolveProviderCapabilityId`.                                                                                                                                                                                                               |
| Side-effect import in a barrel | `import './x.js'` in an `index.ts` counts as a caller (self-registering modules such as the provider bundles); `export *` still does not.                                                                                                                                                                                                                                                                         |
| No backlog reasons             | A baseline reason containing "backlog" fails the check.                                                                                                                                                                                                                                                                                                                                                           |
