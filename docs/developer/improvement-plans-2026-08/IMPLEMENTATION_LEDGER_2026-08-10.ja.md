## 判断記録(スコープの明確化)

- **IP-01 の child_process 除外**: AGENTS.md §1 の不変条件は「ファイル I/O は secure-io、node:fs を直接呼ばない」。libs/core には PTY・ストリーミング音声・CLI バックエンド等で長寿命/ストリーミング `spawn` を使う正当なモジュールが 30 以上あり、safeExec(一発実行)では代替不可。よって IP-01 の ban は **fs/node:fs に限定**し、child_process→safeExec 統制は別途の大規模計画に切り出す。
- **IP-01 と IP-02 の分担**: IP-01 は「enforcement を効かせ、新規の fs 直 import を防ぐ」まで。既存の fs 直 import は IP-02(secure-io 実移行、文書生成への影響検証が必要)で修正する。それまでは IP-02 参照の `eslint-disable-next-line` で抑制する。
- **tests/** の据え置き: tests は setup で fs を多用するため、un-ignore すると大量の抑制が必要になり CI ゲートを乱すため、tests は ignore 継続(fs 不変条件の enforcement 対象外)。tools/** も拡張・静的アセットのため据え置く。
