category: Security

- **secure-io pins chmod and directory listings to the opened descriptor** — `safeChmodSync` now opens files and directories, re-checks the opened location and `fchmod`s it; sockets, FIFOs and devices are refused (the agent runtime supervisor now binds its socket 0600 under a restrictive umask instead of chmod'ing it), and `safeReaddir` lists the directory it actually opened and checked. A symlink flipped between the permission check and the operation can no longer change the mode of, or list, a `knowledge/personal/` file or directory.
- **Appends create only in the directory that was authorized; no hang on FIFOs** — an append creates a missing file only with `O_CREAT|O_EXCL|O_NOFOLLOW`, inside the parent directory as opened and authorized (on Linux through that directory's descriptor, so a parent flipped to a link cannot redirect it; elsewhere such a flip can still leave an empty, refused file behind). A concurrent appender that loses the create appends to the winner's file, so no line is lost. Appending through a dangling symlink now fails even when its target would be allowed. A created file whose vetting fails is left empty, never deleted by path. In-place reads, range and tail reads and copies open non-blocking and refuse non-regular files, so a FIFO no longer hangs the caller.
- **Denial messages name only the caller's path** — secure-io no longer echoes the resolved location (or the tier-guard reason that embeds it) when it refuses access through a link, and errors from its opens and stats carry only the errno, not an absolute path.
- **The checkout root is pinned on platforms without `/proc/self/fd` (macOS, Windows)** — the portable descriptor pin did not recognise the checkout root, so `safeStat` and `safeReaddir` of the root were refused there and a repository walk (`getAllFiles`) returned `[]`. The root is now pinned like any other entry, a failed pin still throws, and `walk` / `getAllFiles` rethrow any failure to list their root other than a missing one, so a refusal never turns into `[]`. Linux CI exercises the portable branch through a test seam.
