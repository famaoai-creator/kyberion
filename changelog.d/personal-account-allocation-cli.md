- Registered personal API-token accounts can serve claimed tenant tasks through
  existing explicit owner-approved service allocations. The local broker reads
  only the selected encrypted generation and rechecks the claim, grant, binding
  and generation on use. Registration alone does not share or allocate a token.
- `kyberion account preview/request/status/apply` uses the existing introduction
  facade and installed owner. Requests bind the exact metadata review under the
  active profile; tokens are collected only after approval at a hidden TTY prompt.
  No token values are accepted through arguments, environment, files or pipes.
- Tenantless claimed execution and GWS session collection remain deferred. The
  existing macOS encryption key is required; no key creation, identity repair or
  live account changes are performed by installing this code.
