category: Fixed

- documentation cleanup: removed seven empty or superseded delivery patches and the duplicate implementation ledger; retained the unimported trading PoC patch and consolidated delivery history into the canonical ledger.
- import review: supervisor self-recycle rejects new mutating IPC before draining and waits for admitted mutations, including pending runtime creation. Mission verification rejects missing or malformed task boards even with an open-task override; open-task refusals return an error to CLI callers.
- secure-io: the private token pipe no longer wraps the runtime's own FD 3 (libuv kqueue on macOS) when no pipe was inherited; it fails with the normal "pipe unavailable" error instead of aborting the process.
- agent-runtime supervisor: the compiler-outputs lock is held only for the pre-sweep and per-dot checks, not across wakes, so a long wake no longer blocks `pnpm build`; a build that starts mid-sweep defers the remaining wakes to the next sweep.
- temporal: `KYBERION_TIMEZONE` pins the installation timezone used for credential budget months and token-expiry defaults (invalid values fall back to the OS zone).
- org budget governor: usage from a provider CLI whose billing mode is unrecorded now counts its provider-reported reference cost against the daily cost cap. Previously one such row made the day's cost "unknown" and hard-throttled the scope until the UTC rollover, so a resident dot woke once per day instead of on its cron. A call aborted before any usage report (wall-clock timeout) now makes the cost partial instead of pausing the scope; its tokens still count through the dot ledger.
- pii-scrubber: the `CREDIT_CARD` rule also requires a card-issuer first digit (2-6). Epoch-millisecond timestamps that happen to pass Luhn (about one in ten dot watch trigger keys) were blocked as card numbers at the reasoning egress gate, failing those wakes. Egress denials now name the matched rule ids (never the value).
- dot watch triggers accept `min_severity` (`info` < `warning` < `critical`): appended jsonl records ranked lower no longer wake the dot by themselves. repo-guardian now wakes at once only for critical ops alerts, runs its cron hourly instead of every 15 minutes (idle bound 75 min), and its daily dot token cap is 1.5M. The installation `org_budget.daily_token_cap` is raised from 3M to 5M; the $50 daily cost cap is unchanged.
- dot wakes: a wake now handles its trigger and completes (event-handler completion mode, no budget grace turn) instead of re-auditing the standing goal until the turn cap; the charter prompt is sent once per turn; watch wakes carry the appended jsonl records (compacted, capped at 1500 chars); idle cron wakes with no new input skip the model (`runtime.force_wake_every_ms`, default 6h, forces a real wake); hypotheses can be resolved as `dismissed` and only the newest 8 open ones are rendered. repo-guardian: `max_turns_per_wake` 4.
- daemon-watchdog: optional resident daemons are watched only when installed and page as warning; a stale/missing daemon pages critical only when the previous recent run saw it too (a long gap since the last run means the host slept); alerts are keyed per daemon with a 60-minute re-page interval and a recovery record. The baseline chronos-dead page fires only when the watchdog's own latest run confirmed the outage (a first sighting seconds earlier is not confirmation).
- pipeline scheduler: schedules record `consecutiveFailures`, `failingSince` and `lastError`, and the failed-schedule sweep alert names the reason.
- health degradation: latency regressions need the last run ≥1000 ms or a ≥500 ms increase.
- security policy: `chronos_gateway` may write `active/shared/observability/ops-findings.jsonl` and `knowledge/product/governance/CURATION_REPORT.md`; `infrastructure_sentinel` may write `active/shared/inbox/entries.jsonl` (dot digest inbox delivery).
- missions: mission repos ignore audio/video evidence (`evidence/audio/`, media extensions) and staging failures warn instead of throwing; record-evidence reports why a task did not close (missing deliverable path, open dependencies); verify refuses while tasks are open unless `--allow-open-tasks "<reason>"`; `minutes:record` without `--mission` creates a `meeting_facilitation` mission (requires a standing recording grant).
- agent-runtime supervisor: under launchd/systemd the daemon recycles itself onto a new core build instead of only warning `stale_code` (it ran stale code for 2+ hours until a manual kickstart). It recycles only between sweeps with no ask, busy runtime or delegated worker in flight, after the dist stamp read under the compiler-outputs lock is unchanged across two checks; it drains runtimes and exits 75 so KeepAlive / Restart=on-failure respawns it, at most once per 15 minutes (`last_self_recycle_at` in the heartbeat). Foreground runs keep warning only; `KYBERION_AGENT_RUNTIME_SUPERVISOR_STALE_CODE_RECYCLE=0` disables it.
- dot wakes: a wake whose wall-clock budget ran out while the host was asleep (macOS DarkWake / Power Nap sleeping again mid-wake; detected as >30 s in which the process did not run) is recorded as `skipped` with `reason_code: host_suspended` instead of `failed`, so the trigger stays due (follow-ups are not lost; cron is covered by catch-up) and the failure circuits ignore it. Genuine overruns remain failures.
- dot wake circuit: one `credential_grant` failure (missing/expired/unusable tenant credential grant) now opens the dot's circuit at once and holds its wakes for 24 h or until the tenant's `credential.use` grants or the charter's routed backend change, with one ops alert per opening — instead of a refused wake every ~6 h indefinitely.
- runtime health trends: RSS growth compares the upper quartile of the first and last thirds of the window and needs ≥50 MB absolute growth, so a paged-out sample right after macOS wake or a GC saw-tooth no longer reads as a 3–15× critical leak.
- generation-schedule daemon: a tick is deferred while a build holds the compiler outputs, and a tick whose `dist/` entry vanished mid-rebuild is skipped instead of alerting; other tick failures carry the child's stderr tail in the alert.
