- **KDS v2 styles on the Surfaces** — every Surface token file now carries `[data-kds-style]` scopes (editorial, midnight-signal, graphite-executive, aurora, paper-minimal) that re-declare the same `--kb-ui-*` tokens, with contrast held per style × theme. Preview with the new Style toggle / `?style=` on `/ui-gallery`. Primary buttons may use an accent gradient (`aurora` only); the "no gradients" component rule is revised accordingly. No change unless `data-kds-style` is set.
