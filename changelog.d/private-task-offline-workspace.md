- **Ordinary private task source preparation** — mission owners can prepare an independently stored, task-scoped offline Git clone at an exact reviewed local commit, without activating publication workflows or copying untracked runtime identity. Source grants retain their original baseline through task updates. Failed clone/checkout rolls back the workspace ledger entry. Isolated test execution is not yet provided and no unisolated fallback is enabled; the required isolation and immutable-snapshot boundaries are documented.
