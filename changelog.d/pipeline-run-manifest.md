---
category: Added
---

- Deterministic tenant pipelines now run on one approval. `pnpm kyberion project-trust request <file>` shows the pipeline's Run Manifest on the approval card in plain language, including each page script's excerpt. Approving it issues a charter bound to that manifest, so matching external steps run without further prompts. Every step still writes its review evidence, once-only commit and audit entry, and any change to the file voids the approval.
- `pnpm pipeline check <file>` reports scope, trust, model, secrets, external-step coverage and run principal together, each with the next command.
- `--allow-unattended` lets an approved manifest run without the approving owner at a terminal. Agent-driven processes always count as unattended.
- `--runs-per-day N` sets a daily cap on bound runs; the default is 20 per UTC day. Runs over the cap fall back to per-step approval.
- `browser:evaluate` accepts `args`, so run-time values reach a static page script as data.
- The tenant is derived from the pipeline file's location.

- `pnpm pipeline check <file>` now prints, for each page script that splices run-time values (`templated_script`), a ready-to-paste `"script"` + `"args"` rewrite that makes the step pre-approvable, or the reason none could be generated. Each suggestion carries a caveat that args arrive as data (a numeric string stays a string). Credentials (`{{env.X}}`, `secret:get` values) are never moved into args. `--suggest-args` prints one line per step (stdout only; the file is never re-serialized or written).
- Browser actuator native scenarios (`{action:"pipeline", steps:[{type, op:"goto"}]}`) are now Run Manifest sources: `pnpm kyberion project-trust request <file>` approves their external steps, including steps inside `if` / `while` bodies, and `pnpm kyberion browser run --adf <file>` (or the actuator CLI `--input`) then runs them without per-step prompts. `pnpm pipeline check <file>` reports their coverage. Unapproved or changed native files run exactly as before.
- `{{env.X}}` values in pipelines are treated as credentials: each may only be typed into the page opened just before it, the approval card names it, and a URL that carries a credential always asks per step. Approved native browser runs keep their step files in the tenant's partition and their browser profile under the tenant profile directory. `pnpm pipeline --input` now refuses a native browser file and names `pnpm kyberion browser run --adf`.
- A native browser step that writes a file outside the tenant's partition (a screenshot or export path) is shown on the approval card and in `pnpm pipeline check` with the confined path to use. At run time it asks for its own approval of that exact path instead of stopping an approved run.
- Approved native browser runs also confine failure-bundle exports and session-handoff imports to the tenant's partition. They never re-attach to an external browser over CDP.
- An approved native browser run no longer gains the caller's read rights. `pnpm kyberion browser run --adf <file>` dispatches under the surface identity whether the run is pre-approved or not. The approval gate reads and records that tenant's charters, the run's ledger entries, reviews and reservations through a grant limited to those files. Session-handoff imports read only the run's own tenant profile, scratch and artifact partitions, not other tenants' browser profiles.
- `pnpm pipeline fix <file>` rewrites what `pnpm pipeline check` can fix mechanically: templated page scripts become `(a) => …` + `args`, native step files outside the run partition move to the confined path, and `options.user_data_dir` moves into the tenant profile partition. It prints a diff with the coverage before and after and lists what needs a manual edit; credentials are never moved into args. `--write` keeps a backup on the tenant artifact floor, edits only the targeted values (no re-serialization) and refuses if the file changed or coverage would drop; `--move-profile` moves the existing profile too. `pnpm pipeline check` names the command when a fix exists.
