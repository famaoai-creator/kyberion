- **Personalized lifecycle guidance** — `kyberion ask` can learn which conversation, recovery, and onboarding routes help you. Follow the guide’s feedback command to evaluate a route, use `guide status` to inspect your learning window, and set a preference to `off` to stop collecting feedback for that topic.
- **Guidance follow-up reporting** — `kyberion conversation report` counts public CLI guidance follow-ups, replies, requests awaiting input, and requests awaiting approval. The first-time setup report exposes first-request readiness in JSON.
