- **Web organization and project management**: Authenticated owners can create organizations and projects within an existing tenant and edit their names, purposes, and summaries from a scope-preserving management page. Confirmations, entity-bound permissions, conflict detection, idempotent retries, and actor-scoped audit protect saves. Changing an organization purpose returns that purpose to draft for reapproval.
- **Scoped mission navigation**: Keep the selected tenant, organization, and project when opening existing mission lists and approved discussion-to-mission flows.
