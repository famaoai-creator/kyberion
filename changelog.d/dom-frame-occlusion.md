- **Frame-aware snapshots + occlusion + structure distillation** — the second half of the browser-use DOM-depth concepts, adopted natively: snapshots now traverse child frames (srcdoc and opaque-origin included — `frame.evaluate` works regardless of origin). Elements inside a frame carry `frame: {url, name, depth}` metadata, an `inner_selector`, and a `selector` that already embeds the `>> internal:control=enter-frame >>` chain, so every existing `page.click(selector)`-style path resolves cross-frame targets with zero call-site changes; nested frames chain recursively. Frames that cannot be harvested are counted in `snapshot.frame_errors` instead of failing the capture, and `frame_count` reports how many contributed. Recorded-target resolution corroborates `dom_path` **inside the element's own frame** (matched by captured url+name); a vanished or relabeled frame fails closed like a missing element. Paint-order occlusion is now reported at capture time: each snapshot element and each `distill_dom` interactive row gets `occluded`/`occluded_by` from a center-point `elementFromPoint` hit test — a visible-but-covered element is no longer presented as actionable, and untestable centers (out of viewport, zero box) leave the flag absent rather than guessed. `distill_dom` gains `mode: "structure"`: a separate judgment-facing inventory (landmarks, headings, containers, document `depth`, `child_count`, frame-stamped rows, `total_candidates`/`truncated` envelope) that deliberately shares no shape with the executable interactive inventory — evaluation data is never an action-target surface. Summary refs now surface `occluded`/`frame_depth` hints for operator triage.
