- **Dialogue Room** — the Discussion Room gains a human-first "work it out with me" mode. A facilitator converses with you and keeps a live goal card (objective, success criteria, constraints, assumptions, decisions, open questions) with a readiness score; when it is ready — or whenever you type `/brief` — the conversation feeds the same decision brief, review, WorkItem and approval-gated mission flow as agent panels. The chat has the expected features: streaming replies with stop, regenerate, edit-and-resend, copy, read-aloud, thumbs feedback, markdown rendering, suggestion chips, slash commands (`/brief /summary /consult /export /help`), `@role` consults, file and image attachments (with text extraction), voice dictation, IME-safe Enter, sessions with search / archive / rename, and markdown export.
