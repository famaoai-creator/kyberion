category: Changed
---

- **Video runtime moved to `@agent/shared-video`** — video ingest, composition compile/render, filters and recut moved out of `@agent/core` into the new `libs/shared-video` package. Update imports from `@agent/core/video/<module>` (and `@agent/core/video/ingest`) to `@agent/shared-video/<module>` (and `@agent/shared-video/ingest`). The video contracts, design system and frame plumbing stay at `@agent/core/video/*`. `tenantOfPath` / `tierOfPath` for scope checks now live in `@agent/core/path-tenant-attribution`. Lint rejects any `@agent/core` import of `@agent/shared-*`.
- **Media production runtime moved to `@agent/shared-media`** — the native docx/xlsx/pptx/pdf generation engines, image/music/video generation bridges and providers, and the media layout/drawio policies moved from `@agent/core/media/*` to `@agent/shared-media/*` (same relative module paths). Readers and parsers that core itself uses (document reader, docx/xlsx/pptx utils, pdf parser, image description) stay at `@agent/core/media/*`.
- **Voice runtime moved to `@agent/shared-voice`** — realtime voice conversation loops, voice generation/TTS orchestration, voice samples, selection preferences and turn-taking moved from `@agent/core/voice/*` to the new `@agent/shared-voice/*` package. Audio bus/route, STT/TTS bridges, VAD and voice-engine registries that core itself uses stay at `@agent/core/voice/*`.
- **Browser bridge and onboarding moved to `@agent/shared-vision`** — the browser automation runtime bridge, extension mailbox, browser conversation session, golden evidence, onboarding and procedure promotion moved from `@agent/core/browser/*` to `@agent/shared-vision/*`. The extension bridge, recording compiler and Chrome meeting driver that core uses stay at `@agent/core/browser/*`.
- **Conversation control moved to `@agent/shared-interaction`** — the modality-independent conversation engine (turn-taking, backchannels, user rhythm, utterance intent, reply structure, language packs) moved from `@agent/core/interaction/*` to the new `@agent/shared-interaction` package, so text chat and meeting facilitation can reuse it without the voice runtime. Package layering is documented in `knowledge/product/architecture/workspace-package-layering.md`.
