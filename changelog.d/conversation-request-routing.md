- **Conversation request continuity** — Concierge and Presence retain multiple requests in the authenticated conversation and answer status questions about them, asking which one when a reference is ambiguous. A request answered directly in the conversation is marked completed with an excerpt of the reply; requests needing input or work beyond the conversation are marked as such. New requests, follow-ups, mixed messages, bare confirmations and unmatched references still reach the conversation runtime unchanged. Approval and cancellation text never grants authority or starts work.
