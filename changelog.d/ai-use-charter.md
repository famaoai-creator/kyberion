- **AI use Charters** — define which model processors may handle which data for which purposes, separately from customer and public recipients. Existing provider egress, attestation, and no-training checks remain in force; unattended customer delivery is limited to an exact greeting for a bound customer. A newly accepted charter also records its recipient scope explicitly: external-send and public-publish decisions delegate nothing until the owner names the recipient flow, so those actions return to a human instead of being inferred from the decision name alone.
