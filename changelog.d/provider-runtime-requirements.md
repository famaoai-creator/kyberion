category: Changed
---

- Add `@agent/core/provider-runtime-requirements`, a reusable runtime-requirements layer for seam providers: `ProviderRuntimeRequirement` declares host platform, accelerator (Metal/MLX), managed-tool, env-command, env-var, and external-tool-binary requirements; `unmetRuntimeRequirements` evaluates them against `platform-facts`, the managed tool-runtime registry, the governed tool-binary resolvers (`isExternalToolBinResolvable`), and the env registry to produce structured `unmet` labels such as `platform:darwin`, `accelerator:metal`, `managed_runtime:mlx_whisper`, `env:KYBERION_TTS_COMMAND`, and `tool_binary:speech_cpp`; `runtimeSetupHint`/`runtimeSetupHintsFromCandidates` map unmet labels to actionable setup guidance (`pnpm tool:setup -- --tool <id> --apply`).
- Streaming STT/TTS selection now evaluates runtime requirements alongside functional capabilities, so runtime-gated providers stay visible as excluded candidates with reasons instead of silently missing and later failing with "backend not found". The managed MLX Whisper streaming STT bridge and the `KYBERION_STT_COMMAND`/`KYBERION_TTS_COMMAND` shell bridges register unconditionally and report `installed: false` with a setup reason when their runtime is unavailable; using an unavailable bridge throws a setup-oriented error.
- Batch speech-to-text selection applies the same layer: `SpeechToTextCapabilities.runtime_requirements` feeds `listSpeechToTextCandidates` unmet reasons, and the `KYBERION_STT_COMMAND` shell, `KYBERION_FLUID_AUDIO_STT_COMMAND` FluidAudio, managed `mlx_whisper`/`faster_whisper`, and `speech_cpp` installers register runtime-gated placeholder bridges that surface excluded-with-reason candidates while `getSpeechToTextBridge()` keeps returning a usable bridge or the stub. Placeholders are released when the runtime becomes available so the real bridge can register.
- Embedding bootstrap candidates declare `runtime_requirements` (e.g. `mlx` → darwin-only); `listEmbeddingBackendCandidates()` reports per-candidate `unmet` reasons and the install loop logs why a candidate was skipped.
- `run_realtime_voice_conversation` appends actionable setup hints to the "requires a real streaming or batch STT backend" error when candidate metadata provides them.
- Review hardening: real seam registrations supersede same-name runtime-gated placeholders; `listSpeechToTextCandidates` keeps `stub` visible on the live provider list; streaming env-gated placeholder disposers are released before the real shell bridge registers so re-configuration cannot hit the named-seam duplicate-provider error; `listStreamingTtsBridgeIds()` checks registration without instantiating bridge factories.
