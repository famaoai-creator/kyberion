- **Docs coherence (CU-11, CU-12, CU-14)** — new generated `docs/CLI_REFERENCE.md` (every `kyberion` command and `pnpm` script, scopes/areas and deprecated aliases) built from `cli-commands.json` and the `cli` vocabulary by `pnpm generate:cli-reference` (`--check` for drift), plus a task-oriented `docs/user/COMMANDS_GUIDE.md` for the everyday commands. `docs/QUICKSTART.md` is now the single front door with an onboarding entry-points table (`pnpm onboarding`, `onboarding apply|company|reset`, `onboarding:context`, `kyberion setup <area>`, and the four onboarding pipelines); `docs/INITIALIZATION.md` is now English (Japanese moved to `INITIALIZATION.ja.md`), `docs/README.md` indexes the scenario and roadmap documents and their canonical copies, the duplicate operations readiness matrix is merged into `docs/user/`, and `docs/user/TROUBLESHOOTING.md` covers the common CLI failures. New `docs-drift` PR gate (`scripts/check_docs_drift.ts`, also `kyberion docs check`) rejects documented `pnpm`/`kyberion` commands that do not exist (bare `pnpm doctor` is an explicit error), pipelines missing from `pipelines/README.md`, top-level directories missing from `COMPONENT_MAP.md`, and a stale CLI reference; known exceptions live in `docs-drift-baseline.json`. `MAX_PACKAGE_SCRIPTS` ratchet raised 128 → 129 for `generate:cli-reference`.
