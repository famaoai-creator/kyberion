- **Optional `agent-desktop` AX backend for `computer_interaction`** — when the managed tool runtime is installed (`pnpm tool:setup -- --tool agent_desktop --apply`, or `KYBERION_AGENT_DESKTOP_BIN`), `computer_interaction` gains AX-tree ops: `ax_runtime_status` (preflight probe that answers even when the runtime is absent), observation ops (`ax_snapshot`, `ax_find`, `ax_list_windows`, `ax_list_apps`, `ax_list_displays`, `ax_list_surfaces`, `ax_list_notifications`, `ax_get`, `ax_is`), navigation-class ops (`ax_click`, `ax_scroll`, `ax_scroll_to`, `ax_focus`, `ax_expand`, `ax_collapse`), commit-class ops behind `wf_computer_destructive_v1` approval (`ax_type`, `ax_press`, `ax_set_value`, `ax_select`, `ax_clear`, `ax_toggle`, `ax_check`, `ax_uncheck`, `ax_right_click`), and lifecycle ops (`ax_session_end`, `ax_session_gc`). Targets use snapshot-qualified refs (`@<snapshot>:e<N>`); stale or cross-snapshot refs fail closed with `re_observe_then_retry` guidance, and mutating ops report honest delivery dispositions including `delivered_verified` via postcondition readback. When the runtime is absent every `ax_*` op returns a structured `TOOL_UNAVAILABLE` result — non-AX paths are unaffected.
