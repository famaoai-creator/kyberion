- **Orphan-wiring review fixes** — the weekly reconcile schedules (config fallbacks, unclassified errors, unhandled intents) now ship disabled; a host opts in by listing the schedule id in `KYBERION_CHRONOS_SCHEDULES`, which now also turns on any schedule that ships `enabled: false`. The config-fallback sweep only proposes changes until you pass `pnpm kyberion reconcile config-fallbacks --apply`. `pnpm kyberion hooks trust` opens an approval card that names the hook commands (event → command) the approver is trusting. `pnpm kyberion deals --quote/--draft-contract/--review-contract/--handoff` writes under the governed mission-controller role and takes `--tenant` when a deal id exists in several tenants. Environment variables removed in 2026-10 (`KYBERION_SUDO_KEY`, `KYBERION_TELEMETRY`, `KYBERION_SOVEREIGN_SECRET`, the operator-learning dispatch registry paths) stay registered for one release and only produce a "deprecated, unset it" warning. Also fixed: a hook config approved after startup now registers without a restart, unknown judgment provider ids warn only once, actuator errors from single-action handlers are kept, and `terminal:write_terminal` sends every key in the sequence. The orphan check now counts only real imports and op dispatches, and lists docs-only pipelines separately.
