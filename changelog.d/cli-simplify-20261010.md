- **Deprecated pnpm script aliases** — the 20 old script names (`pnpm onboard`, `pnpm ingest`, `pnpm chronos`, `pnpm dev`, `pnpm inventory`, `pnpm customer:*`, etc.) no longer work. Use the canonical names (`pnpm onboarding`, `pnpm knowledge:ingest`, `pnpm scheduler`, `pnpm verify`, `pnpm work:inventory`, `pnpm stance:*`). The same applies to the old `pnpm kyberion` command words. Run `pnpm kyberion --help` or see `docs/CLI_REFERENCE.md` for the canonical list.
