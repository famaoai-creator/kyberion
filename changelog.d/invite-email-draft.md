- **Invite by e-mail (as a draft)** — after creating an invite you can enter the person's address and make a mail **draft** in your own mail app with the join link. Nothing is sent for you: you review and send it yourself. If no mail app is available the pane says so and you copy the link as before. The code is only used to build the link; it is never logged.
