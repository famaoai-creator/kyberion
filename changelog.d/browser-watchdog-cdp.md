- **Browser runtime watchdog + governed `cdp` escape lane** — adopting the browser-use session model natively: ops declare intent, watchdog observers record and contain what the page does between steps. `watchdog_events` (capture) returns bounded per-kind event buffers — `dialog`, `download`, `crash`, `popup`, `navigation`, `close` — and `session_health` now embeds a `watchdog` summary. Dialogs are settled by an explicit policy (`dialog_policy` apply op: `accept` | `dismiss`, default `accept` preserves prior behavior) and every settle is recorded with its disposition. Crashed tabs fail closed: `getActivePage` throws `[BROWSER_TAB_CRASHED]` and same-renderer multi-tab crashes mark every affected tab. Closing the active tab clears `activeTabId` instead of silently retargeting. `cdp` (capture) is a page-scoped raw-CDP lane for what Playwright cannot reach (DOMSnapshot across cross-origin frames, full AX tree, paint-order geometry): domain allowlist (DOM/DOMSnapshot/Accessibility/Page/Runtime/Input/…), method denylist (`Page.setBypassCSP`, `Page.addScriptToEvaluateOnNewDocument`, `Runtime.addBinding`, …), bounded `timeout_ms` (≤60s), human admission parity with `evaluate`, and the raw method lands in the action trail/ADF for audit. Runtime capability `raw_cdp` is wired (Lightpanda: `false`), so `browser:cdp` preflight-refuses on runtimes without a CDP session — the Chrome extension path is unaffected since the op only exists on the runtime pipeline.
