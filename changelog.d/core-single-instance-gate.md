category: Changed

- **One `@agent/core` per process** — the TypeScript loader (`scripts/ts-loader.mjs`) now chooses the built dist or the source of `@agent/core` once per process: the first `@agent/core` import picks dist when `libs/core/dist/index.js` exists (source otherwise), and a bootstrap script's first relative core import picks source. A missing dist subpath (stale or partial build) is no longer answered from source next to loaded dist modules, and a dist built while a source process runs is not picked up by it, so `pnpm build`'s readiness checks reuse the source modules the bootstrap already loaded instead of loading a second copy. A new pr gate, `core-single-instance` (`scripts/check_core_single_instance.ts`), fails when production code outside `libs/core` imports a libs/core module by relative path in any runtime form (static, side-effect, re-export, dynamic `import()`, `require`, including `../../core/` from inside `libs/`); only the build/clean bootstrap files and the loader's cache module are listed, each with a reason, and a stale entry fails the gate. The overlapping regex checks in `check_esm_integrity.ts` and `tests/package-boundary-contract.test.ts` (and their four stale allowlist entries) are removed.
