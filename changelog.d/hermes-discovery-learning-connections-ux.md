- **Service discovery** — search the service catalog by name and connection method, open supported browser sign-in explicitly, and retry failed catalog loads. Recorded connections show their owner and distinguish configuration from verified authentication.
- **Learning review and recovery** — inspect the saved proposal separately from unsaved edits. Background-review proposals support pinning, maintenance opt-out, reasoned archive previews, and explicit restoration to review without applying knowledge changes.
- **Terminal navigation** — use Ctrl+P to search panels and safe actions, return to a preserved composer draft with Escape, and find the service settings URL from the terminal.
- **Bounded tool discovery** — large deferred tool catalogs use a finite UTF-8 byte budget and progressively shorter listings while retaining the original tool permissions.
