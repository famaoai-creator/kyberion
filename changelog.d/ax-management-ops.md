- **Management ops on the optional `agent-desktop` AX backend** — `computer_interaction` gains 17 governed `ax_*` ops: observation `ax_wait` (server-side blocking waits on element / window title / text / menu / notification / lifecycle events — stronger than a client retry loop because upstream polls inside the session namespace) and `ax_permissions` (accessibility / screen-recording / automation grant states); navigation-class window management (`ax_focus_window`, `ax_move_window`, `ax_resize_window`, `ax_minimize_window`, `ax_maximize_window`, `ax_restore_window`, `ax_open_system_surface`); commit-class app lifecycle (`ax_launch` with `--activate` / `--cdp` / args / env / cwd, `ax_close_app` with `--force`), notification ops (`ax_dismiss_notification`, `ax_dismiss_all_notifications`, `ax_notification_action` — upstream-required `expected_app` / `expected_title` identity fields enforced before positional dismiss), and clipboard ops (`ax_clipboard_get` gated as a sensitive read, `ax_clipboard_set`, `ax_clipboard_clear`). `action.agent_id` maps to upstream `--agent-id` / `AGENT_DESKTOP_AGENT_ID` for per-actor trace audit inside a shared session namespace.
- **Honest error pass-through** — upstream `error.disposition` and `error.recovery` now surface on results (a `TIMEOUT` mid-dispatch reports `delivered_unverified` + `retry: unsafe` rather than `unknown`; policy denials carry upstream's remediation strategy); bare-array payloads (`list-windows`, `list-displays`) mark their evidence field `known`; `WINDOW_NOT_FOUND` / `APP_NOT_FOUND` / `NOTIFICATION_NOT_FOUND` classify as `not_delivered` + `re_observe_then_retry`, `PERM_DENIED` as `grant_permissions` (non-retryable).
