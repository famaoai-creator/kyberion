category: Added
---

- Concierge can request owner approval to register API tokens for an existing
  connection, then collect and encrypt an exact account generation. Personal
  approvals and saved material remain isolated from organization allocation.
- Organization registration can provision an explicitly configured account writer
  with generation conflict detection and exact response validation. Existing
  read-only resolver commands receive no registration values.

- Incomplete writes require operator recovery. Personal runtime brokerage, tenantless
  task execution, GWS session collection and CLI account registration are not included.
