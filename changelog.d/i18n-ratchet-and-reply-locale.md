- **i18n debt closed out, locale/colour ratchet added, reply-locale gaps fixed (IT-05, IT-02 follow-up, IT-04 tenant threading)** — the remaining Japanese-literal baseline is now zero: browser-conversation feedback moved to the `browser_conversation` vocabulary domain and its Japanese target / input extraction regexes to lexicon extraction concepts (`captureIntentPhrase`); execution-feedback outcome words come from the phrase lexicon; the CEO summary fallback titles use vocabulary keys; best-of-N directives are English-only prompts; deliberately Japanese content (quote / contract documents, the qualified-invoice format, concierge/companion hero copy, the status_ja contract field, the JA demo deck) carries `i18n-exempt` reasons. `check_i18n_hardcoding.ts` (now a `pr`-scope gate) also freezes per-file counts of Japanese intent regexes, ad-hoc `=== 'ja'` / `=== 'en'` comparisons, hard-coded `ja-JP` / `en-US` tags and raw colour values across the artifact-engine directories (a string that is a colour token, or a colour in a CSS declaration or markup attribute — not prose such as `Ticket #123`; locale tags passed straight to `toLocaleString` / `Intl.*` for machine-stable output are exempt) — counts may only go down (`locale_tokens` in `i18n-baseline.json`). Reply locale: a turn with no language signal now falls back to the locale stored for its tenant/organization/project scope before the operator locale — the tenant locale (`knowledge/confidential/<tenant>/locale.json`) is read under the new least-privilege `scope_locale_reader` role bound to the turn's tenant, so surface runtimes that cannot read the confidential tier still honor it, and an unreadable organization/project overlay warns once instead of failing silently; proactive approval cards (Slack blocks, surface text, decision cards) resolve the approval's scope locale instead of a hard-coded `en`, and the Slack approve/reject confirmation is localized. `createPptxLayoutKit({ tenantSlug })` binds a render's tenant once so the pptx palette, header and footer all apply the tenant's semantic-token overlay (the layout showcase script takes `--tenant`).
