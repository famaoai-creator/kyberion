- **Scoped development delegation** — the existing onboarding charter can review data tiers and verified-private repository grants, activate the agent and delegate PR creation, candidate-branch push and base-branch merge in one owner decision. The default reusable candidate is `agent/kyberion-development`; direct pushes to `main` are excluded. Public, personal and tenant-confidential source boundaries remain explicit.
- **Prepared WorkItem VCS reconciliation** — `vcs:development_loop` uses the existing VCS actuator, independent artifact-review receipts and server-required CI evidence. It defaults to dry-run and distinguishes waiting, repair/review requirements, queued merges and merge-commit CI verification. Implementation and repairs remain with the existing mission executor.
