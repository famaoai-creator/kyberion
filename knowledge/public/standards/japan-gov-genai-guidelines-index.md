## 2. AIDP 第1.1版（金融庁 2026-03）の骨格 — 実務で使える枠組み

金融分野の AI 利用におけるリスク低減の4観点（AI官民フォーラムの取組事例から整理）:

1. **設計と事前検証** — サービス提供前の設計・評価
2. **顧客への適切な説明・注意喚起** — 提供時の透明性
3. **検証・モニタリング** — 提供後の継続検証
4. **ガバナンス** — 全体を支える体制

全社的課題9項目: データ整備 / ガバナンス構築 / 社内ルール策定 / 人材確保 / 投資対効果 / モデルリスク管理 / サードパーティ選定 / 情報セキュリティ / 金融犯罪対策。
個別AI課題5項目: 説明可能性 / 公平性・バイアス / ハルシネーション / 個人情報保護 / 規制対応。
金融庁の基本スタンスは技術中立（既存法令はAI利用の有無に関わらず適用）＋ セーフハーバー提供の志向。

## 3. AI事業者ガイドライン（総務省・経済産業省）の骨格

AI 開発者・提供者・利用者向けの統一ソフトロー（非拘束・ゴールベース）。「人間中心のAI社会原則」を土台に3つの旧ガイドライン（AI開発・AI利活用・ガバナンスガイドライン）を統合。共通の指針10原則に加え、主体別の重要事項を定義（安全性／セキュリティ確保／公平性／プライバシー／透明性／アカウンタビリティ／教育・リテラシー／公正競争確保 等）。広島AIプロセス報告枠組みの運用開始（2025-02）と整合。

## 4. 運用上の注意

- **FISC 第14版の AI 安全対策項目はこれらガイドライン群の反映** — 条文案の原文確認には FISC 解説書 第14版（会員/有償）が必要。
- **版ドリフトが速い** — 本索引の URL・版情報は 2026-10-05 時点。次回棚卸し（evergreen 365日周期、~2027-10）以前でも、基準項目の新設・条文案確定が必要になった時点で再確認すること。
- 本エコシステムの AI 利用（reasoning providers, LLM 経由タスク）に対しては AIDP の4観点（設計・事前検証 → 説明 → 検証・モニタリング → ガバナンス）が最も実務的な自己点検フレーム。
