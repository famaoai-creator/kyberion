# Preserve explicit empty authority sets at viewer narrowing boundaries

An already resolved empty cap is the bottom authority set; defaults belong to upstream resolution.

## Hint Scope

mission

## Trigger Phrases

- For a server-resolved viewer cap, narrowing must check membership in the supplied set. An explicit empty array denies every tier; missing or non-array resolved values fail closed. Apply role defaults only in the upstream resolver where omission and emptiness are distinguished. Model every subset of the finite tier universe, verify grant-removal monotonicity, compare the implementation with an independent bitset oracle, and include a default-restoration negative control plus the actual caller. Keep credential, custody, tenant and audience policy outside this limited assurance claim.
