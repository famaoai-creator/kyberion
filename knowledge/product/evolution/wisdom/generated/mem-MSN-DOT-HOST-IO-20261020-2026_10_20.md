# Advisory execution must separate host bookkeeping from model authority

Keep planner execution read-only while allowing only exact synchronous host trace and quota leaf IO under the current tenant and intersected resource ceilings.

## Hint Scope

mission

## Trigger Phrases

- A real native Dot wake exposed host delegation trace and quota-lock writes inside its advisory sandbox. Scope the exception to closed synchronous file operations after serialization and validation. Preserve provider, cancel callback, serialization, network and parent resource restrictions. Verify both durable receipts and denied arbitrary writes. A successful manual wake does not establish inbox dispatch or mission admission; those need actual trigger and WorkItem-to-mission receipts.
