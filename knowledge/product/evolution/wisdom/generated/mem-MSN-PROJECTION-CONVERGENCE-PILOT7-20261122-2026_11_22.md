# Canonical projections live at the lowest layer that consumes them

When converging scattered union-literal branches onto shared predicates, place the vocabulary + predicates at the lowest module layer with a legitimate consumer; module-boundaries enforces the placement and re-exports keep the surface stable.

## Hint Scope

mission

## Trigger Phrases

- Converging if-branch literals onto canonical projections (delegable flags, IO op classes, charter-scope and custody unions) works best inventory-first: classify each literal site as registry-derivable, context-forced, or validation-edge before migrating; guard the result with a repo-scanning contract test that requires reasoned, staleness-checked allowlist entries. Placement rule: the module-boundaries gate caught a foundation->domain import the moment a foundation capability consumed charter predicates — sinking CharterScope vocabulary into libs/core/foundation/charter-scope.ts and re-exporting from accountability-charter.ts fixed the direction violation with zero API churn. Split IO projections by semantics (content-mutating vs placement-mutating vs read-like) rather than one mutating predicate: mkdir mutates the tree but writes no content, and several checks depend on the distinction. Custody unions (CustodyOwner, ViewerRecordCustody, ResourceAccessCustody, AssetCustody) share kind vocabulary but differ in fields — give each union its own predicate names to prevent conflation.
