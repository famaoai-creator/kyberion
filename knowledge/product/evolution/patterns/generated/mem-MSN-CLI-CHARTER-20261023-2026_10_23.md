# Charter delegation only applies inside the runtime authority context

Charter grants are consulted only when the operation runs under withRuntimeExternalOperationAuthority (pipeline execution). Standalone CLI entrypoints like kyberion pr create must wrap their publish call themselves, otherwise the approval gate always demands a human decision.

## Expected Outcome

Diagnosed on MSN-CLI-CHARTER-20261023: EXTERNAL_APPROVAL_REQUIRED kept firing for pr create despite a live grant because publish_pull_request.ts never installed the resolver. Wrapping publishWithWorktreeGovernance in withRuntimeExternalOperationAuthority({stepId,runId}) fixed it. Checklist for new external-op call sites: wrap dispatch in the runtime authority context, keep the body file on a public floor for the pr_create grant to match.
