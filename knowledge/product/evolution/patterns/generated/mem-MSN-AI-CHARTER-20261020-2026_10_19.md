# Separate AI processors from external recipients in autonomy decisions

Charter decisions should evaluate model processing and recipient delivery as separate information flows, each constrained by purpose and data category.

## Applicability

- mission
- mission:MSN-AI-CHARTER-20261020

## Reusable Steps

1. Charter decisions should evaluate model processing and recipient delivery as separate information flows, each constrained by purpose and data category

## Expected Outcome

When delegating AI work, classify the model provider as a processor with an explicit processing purpose and allowed data categories. Evaluate public posting, customer delivery, and other recipients independently using audience identity, purpose, data category, and attachments. A company name or confidential label alone should not prohibit processing when an approved processor and no-training boundary authorize it; missing or mixed facts should fail closed. Keep independent retention, provider attestation, domain egress, and no-training controls in force. Permit unattended external actions only within explicit Charter envelopes; for example, a bound-customer greeting can be routine while substantive or sensitive content remains gated.
