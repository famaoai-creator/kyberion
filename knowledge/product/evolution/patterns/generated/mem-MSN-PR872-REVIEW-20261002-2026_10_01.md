# Bound durable transcript text after redaction

Credential redaction can expand valid input beyond storage limits and poison durable conversation history.

## Applicability

- mission
- mission:MSN-PR872-REVIEW-20261002

## Reusable Steps

1. Credential redaction can expand valid input beyond storage limits and poison durable conversation history

## Expected Outcome

Validate incoming text, redact all recognized credentials, then bound the persisted projection to the corresponding input or reply limit enforced by the history loader. Apply this order to both user requests and assistant replies. Truncating before redaction can split secret patterns, while validating only the original text lets short credential assignments grow into records the loader rejects. Regression coverage should use repeated short credential assignments near both input and reply limits, restore the result, and verify a subsequent request still completes. PR872 review reproduced this issue with password=a repeated 744 times.
