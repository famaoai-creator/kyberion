# Keep discovery, saved review state and execution authority separate

Search, bounded tool announcements, restored proposals and retained drafts improve usability only when they preserve the existing execution and publication boundaries.

## Applicability

- mission
- mission:MSN-HERMES-UX-20261028

## Reusable Steps

1. Search, bounded tool announcements, restored proposals and retained drafts improve usability only when they preserve the existing execution and publication boundaries

## Expected Outcome

When improving agent discovery or connection UX, extend the existing catalog, approval and publication facades rather than introducing a second authority. Bound deferred-tool announcements in UTF-8 bytes and retain role filtering; a byte budget is not an exact token count. Show the saved review payload and digest separately from editable text so an unsaved edit cannot appear to be the approved snapshot. Pin, hold and restore maintenance operations must use exact existing scope and shared candidate locking; a restored proposal returns to review and must not become approved or published. Connection configuration and provider availability are not authenticated connection success. A navigation picker must not execute shell commands or authenticate implicitly. Preserve busy composer input as a draft and label it as unsent; do not present it as a durable queue. Validate these distinctions with race, scope, failure/retry and keyboard fixtures, and report browser or live-account verification separately.
