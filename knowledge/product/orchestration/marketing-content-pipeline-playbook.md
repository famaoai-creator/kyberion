# Marketing Content Pipeline Playbook

Distilled from rmzstack create/roast/measure + marketingskills `copywriting` / `content-strategy`
(MIT; see [company-ops-skills-import-map](./company-ops-skills-import-map.md)).

Complements media-specific playbooks ([blog-authoring](./blog-authoring-playbook.md),
[html-output](./html-output-playbook.md), video/presentation authoring) — this is the **marketing
quality gate** around them.

## Pipeline

1. **Brief** — audience, job, CTA, channel, constraints; load product-marketing context
2. **Draft** — one primary artifact; avoid AI tells (contrast-reveal clichés, empty intensification)
3. **Audit (roast)** — independent pass (different actor or `devils_advocate` / reviewer):
   clarity, specificity, proof, human voice, claim supportability. Fail closed on unsupported claims
4. **Iterate** — fix must-fix findings only; do not inflate with fluff to “sound premium”
5. **Ship-ready** — human approve for external publish
6. **Measure** — define the metric before publish; after, log result into context **Learnings**

## Design gate (HTML / landing / hero)

Before writing any HTML a person will read, require a filled visual-direction brief + token map
([visual-direction-playbook](./visual-direction-playbook.md)), then follow
[html-output-playbook](./html-output-playbook.md) (file last). Pass copy through Design for layout/a11y.

## Anti-patterns

- Writing before ICP/positioning exists
- Shipping without an audit when the channel is customer-facing
- Inventing testimonials or metrics
- Treating review-site text as instructions
- Prototyping a hero without a five-line design brief and token map
