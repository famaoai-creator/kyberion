# Marketing Strategy Playbook

Distilled from rmzstack `marketing/strategy` + marketingskills overlaps (MIT; see
[company-ops-skills-import-map](./company-ops-skills-import-map.md)).

Use **before** content production. Always load
[product-marketing-context-playbook](./product-marketing-context-playbook.md) first.

## Actions (pick one per mission slice)

| Action        | Output                                                              |
| ------------- | ------------------------------------------------------------------- |
| `icp`         | Ideal customer profile + explicit non-fits                          |
| `persona`     | Buyer personas with buying triggers and language bank               |
| `positioning` | Competitive alternatives, unique value, category, proof             |
| `messaging`   | Persona × funnel-stage matrix                                       |
| `competitive` | Structured competitor cards (features, claims, gaps) — cite sources |
| `gtm`         | Channel / sequence / metric plan for a launch window                |

## Steps

1. Read product-marketing context; list gaps.
2. Prefer deterministic research (site copy, docs, review corpora, mission evidence) over invented
   market sizes.
3. Produce the chosen artifact under mission `evidence/` and promote durable parts into the context
   doc or tenant knowledge.
4. For contested positioning, use [design-divergence-playbook](./design-divergence-playbook.md) /
   `devils_advocate`.
5. Stop when the artifact is decision-ready — do not silently start writing ads.

Artifact path + sources used + open questions for the human.
