# Launch / GTM Playbook

Distilled from marketingskills `launch` + rmzstack strategy `gtm` (MIT; see
[company-ops-skills-import-map](./company-ops-skills-import-map.md)).

Use for product/feature/site launches and public announcements. Ongoing always-on marketing after
launch is a different mission (content pipeline + measure).

## Steps

1. **Load context** — [product-marketing-context-playbook](./product-marketing-context-playbook.md)
2. **Define the launch** — audience, single primary CTA, success metric, date window, risk
   (brand, legal, pricing, security)
3. **Pre-launch checklist**
   - Positioning + one hero message agreed
   - Proof assets exist (demo, docs, screenshots) with rights cleared
   - Pricing/packaging human-approved if shown
   - Support / rollback / FAQ ready
   - Channel list with owner and draft status (site, email, social, partners)
4. **Sequence** — teaser → launch day → follow-up; do not spray every channel with the same paste
5. **Governed publish** — customer-facing posts go through approval surfaces; no silent public push
6. **Measure & learn** — capture metric vs target; append Learnings to marketing context

## Kyberion specifics

- Prefer existing media playbooks for the artifact form (blog, HTML, video, deck)
- Dog-food rule: customer-facing launch evidence stays mission/pipeline scoped
- Cross-system change (site + billing + CRM) may require `operator` obligation

## Evidence

Launch brief, checklist status, channel drafts, approval ids, post-launch metric snapshot.
