# 日本語の校正で変えてよいことと、変えてはいけないこと

校正は、読み手に届くように直す作業である。確度、判断した主体、数値、出典の主語は動かさない。硬い言い回しへの置き換えは、事実の追加ではない。

**適用**: 会議資料、報告、説明文を、すでにある原文から校正するとき。章の分け方や「状況と提案を混ぜない」は [人が読む報告資料の書き方](./human-report-writing-practices.md) に従う。

この文書は、校正エージェントの文脈へ渡すための規則である。任務の文面に「校正」「日本語」「報告資料」が含まれると、知識の検索でこの文書が候補になる。

---

## 1. 読み手の立場で直す

届ける相手として一文を読み、そこでつまずく箇所だけを直す。

- 主語と述語が合わない文を直す。「今回の攻撃は、サービスを理解し」は、理解するのが攻撃者なら主語を攻撃者にする。
- 指示語の指す先が二つに読めるときは、直前で名付けたものを書く。「こちらの基盤」は、認証の基盤にもモバイルバンキング基盤にも読める。
- 読み手に説明のない符牒は、中身を増やさずに開く。`High` は「重要度の高い」。製品の「版」は「バージョン」。件数なら、何の件数かを書く。
- 同じ対象を章ごとに別名で呼ばない。リードで付けた名前を、表でも使う。
- 文脈で一意に決まる誤字は直す。文が「エラーを見つける」なら「補足」は「捕捉」である。どちらにも読めるときは原文のまま、書き手に確認する。
- 終わった出来事は、同じ段落の過去と時制をそろえる。いまも続く一般論は現在のままにする。
- 敬語を上げる依頼がない限り、語調は変えない。文書の題は変えない。

要点は先に置く。日時、件数、出典の URL は表か経緯に残す。短くするときも、その数値は落とさない。

## 2. 確度と主体は上げない

次の置き換えは、読みやすく見えて主張が変わる。原文を残すか、変えるなら書き手に確認する。

| 原文が言っていること             | 校正でやってはいけないこと                               |
| -------------------------------- | -------------------------------------------------------- |
| 同じ型である                     | 「完全に一致」にする                                     |
| 〜とみられる                     | みられるを外して断定する                                 |
| まだ確認できていない             | 「特定できていませんでした」と、確認が終わった過去にする |
| 担当者がその時刻に判断した       | 生成AIがその時刻に特定した、に主体を移す                 |
| 可能性を挙げていた               | 誤認した、に確定する                                     |
| システムでは検知がなかった       | 検知の設定がなかった、と原因まで書く                     |
| 公表側が名称の使用を確認した     | 主語を消し、自社が確認したように書く                     |
| 証明書のように誰でも見られる記録 | 透過性ログなど、原文にない仕組みの名を書く               |
| 認可の抜け                       | BOLA など、原文にない分類名を足す                        |
| アプリに組み込んだ鍵             | 秘密鍵など、別種の鍵を足す                               |
| どこからでも接続できた           | 管理ポートが開放されていた、と部位まで特定する           |
| 多要素認証を整備している         | 義務化した、と決定済みにする                             |
| 使われていない管理者の鍵         | 休眠アカウントや特権 ID など、別の対象に言い換える       |

見方の切り替えを担う「ではなく」は残す。「量ではなく、正規の利用では起きない形」は、量を見なくてよいという意味ではない。

書き手が置いた対比（特定の事案名との違いを含む）は、要約しても一文で残す。頼まれて短くするときも、対比の相手を消して「事前の公表はない」だけにしない。

## 3. レビューの印を本文へ入れるとき

手順は [人が読む報告資料の書き方](./human-report-writing-practices.md) の「運用上の注意」に従う。印を外したあとの文は、この文書の第1節と第2節で判断する。

- 注が「消し」なら、印の範囲を削除する。
- 注が続きの文なら、印の範囲とその文を一つの文にする。隣の文と二重にならないようにする。
- 注が新しい名前なら、その名前を本文に使い、同じ対象の古い呼び名もそろえる。

印の文言、コメント番号、前の版との差分は本文に残さない。

## 4. 終える前に見ること

1. 直した文の主体は、原文の主体か。
2. 確度は上がっていないか。未確認は未確認のままか。
3. 数値、時刻、出典の URL は残っているか。
4. 出典にある名称は、出典の側の話のままか。
5. 題名と語調は、依頼がない限り元のままか。
6. 同じ対象の呼び名は、資料の中で一つにそろっているか。

機械的な検査は、意味が保たれたことの合格ではない。意味が変わる候補がゼロでも、上の6項目は原文と照らす。直しは一巡までとし、二巡目で言い回しを盛らない。
