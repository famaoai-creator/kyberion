# Claude に聞く効率チェック質問リスト

ツールの使い方が非効率になっていないかを、**Claude 自身に問い合わせて**判断するための質問。
そのままコピーして投げられる形にしてある。

## 使い方の原則 — 実測で答えられる質問だけが役に立つ

「効率的に使えていますか？」と聞くと、**もっともらしい自己評価が返ってくるだけ**である。
役に立つのは、Claude が**その場で測ってから答えられる**質問だけ。

どの質問にも、迷ったらこれを付ける。

> **この質問に実測で答えられますか。測れないなら「推測」と明記してください。**

以下、A〜C と F は**実測で答えられる**。D は**Claude に聞いても答えが出ない**（人しか知らない）。
E は判断で、実測と人の意図の両方が要る。

---

## 最初に聞く3つ（効果が大きい順）

1. **このセッションのツール出力の上位10件は何で、それぞれ文脈に残す必要がありましたか。**
2. **いま1ターンあたり何トークン再読込していますか。序盤の何倍ですか。**
3. **直近で「読む量が多く、結論だけ要る」作業は何でしたか。委任しましたか。しなかった理由は。**

## A. 何にトークンを使っているか（実測可能）

| #   | 質問                                                                  | 問題の兆候                                                 |
| --- | --------------------------------------------------------------------- | ---------------------------------------------------------- |
| A1  | ツール出力の上位10件は何で、文脈に残す必要があったか                  | **自作の中間ファイル**・ログ・巨大ファイルの丸ごと読み     |
| A2  | 1ターンあたりの cache_read は何トークンか。序盤の何倍か               | 40万超。以後、1ターン進めるだけでその分を払う              |
| A3  | `Read` の件数と平均出力サイズは。範囲読みに置き換えられたものは何件か | 平均1万文字超／置き換え可能が半分以上                      |
| A4  | 本文がほぼ空の結果は何件・何%か                                       | 5%超（探索を単発で撃っている）                             |
| A5  | 権限で止まった呼び出しは何件か。同じ形を繰り返していないか            | 同種の拒否が2回以上                                        |

## B. 委任の判断（実測＋判断）

| #   | 質問                                                         | 問題の兆候                                   |
| --- | ------------------------------------------------------------ | -------------------------------------------- |
| B1  | 「読む量が多く結論だけ要る」作業を自分の文脈でやっていないか | 一覧の機械的処理を自分でやっている           |
| B2  | 委任した作業で、結論以外が私の文脈に入ったものはあるか       | 中間ファイルのパスを受け取って読み返している |
| B3  | 委任した作業の再作業率は。品質が落ちてやり直したものは       | 制約が伝わっておらず作り直し                 |
| B4  | 委任すべきでなかったものはあるか                             | 判断そのもの・ユーザーとの合意が必要なこと   |

## C. 同じ失敗の再発（実測可能）

| #   | 質問                                                 | 問題の兆候                   |
| --- | ---------------------------------------------------- | ---------------------------- |
| C1  | 同じ診断を2回以上やり直したものはあるか。原因は      | ビルド順の失念・発生源の誤診 |
| C2  | 仮説を変えずに同じことを再試行した箇所はあるか       | 1回でもあれば規律違反        |

## D. Claude に聞いても答えが出ない（人しか知らない）

**これらは Claude に投げても意味がない。** 自分で答えて Claude に伝える側の質問である。
（聞けば何かは答えるが、それは observation ではなく作文になる）

- 私の回答で、読まずに飛ばした部分はどこか
- 長く説明しすぎている領域はどこか。逆に足りないのはどこか
- 確認を取るべきだったのに勝手に進めた判断はあるか。逆に聞きすぎたものは
- 出てきた成果物は、そのまま人に見せられる状態だったか

**Claude に聞くとしたら、こう変える。**

> 私が飛ばして読んでいそうな箇所を、あなた自身の出力から挙げてください。
> 根拠（長さ・重複・前置き）も示してください。

## 実測のしかた

Claude が A〜C に答えるための集計。トランスクリプトは
`~/.claude/projects/<project>/<session-id>.jsonl`。

```python
import json, collections
f = '<transcript.jsonl>'
pend = {}; rows = []; cache = []
for line in open(f, encoding='utf8', errors='replace'):
    line = line.strip()
    if not line:
        continue
    try:
        d = json.loads(line)
    except Exception:
        continue
    m = d.get('message') or {}
    if m.get('role') == 'assistant':
        u = m.get('usage') or {}
        if u.get('cache_read_input_tokens'):
            cache.append(u['cache_read_input_tokens'])
        for c in (m.get('content') or []):
            if isinstance(c, dict) and c.get('type') == 'tool_use':
                i = c.get('input') or {}
                pend[c.get('id')] = (c.get('name'), str(i.get('file_path') or i.get('command') or '')[:70])
    if m.get('role') == 'user':
        for c in (m.get('content') or []):
            if isinstance(c, dict) and c.get('type') == 'tool_result':
                s = c.get('content')
                txt = s if isinstance(s, str) else json.dumps(s, ensure_ascii=False)
                rows.append((len(txt), *pend.get(c.get('tool_use_id'), ('?', ''))))
rows.sort(reverse=True)
print('上位10件:'); [print(f'  {n:>8,} {t:10} {g}') for n, t, g in rows[:10]]
q = len(cache) // 4
print('cache_read/turn 序盤', sum(cache[:q]) // max(1, q), '→ 終盤', sum(cache[-q:]) // max(1, q))
by = collections.defaultdict(list)
for n, t, _ in rows:
    by[t].append(n)
for t, v in sorted(by.items(), key=lambda x: -sum(x[1]))[:6]:
    print(f'  {t:12} {len(v):4}件 合計 {sum(v):>9,} 平均 {sum(v)//len(v):>6,}')
```

**この集計自体を `Read` でやらないこと。** 出力だけを取り出す（A1 の趣旨そのもの）。
