# Kyberion Coordination

Use this skill when work should remain aligned with Kyberion governance.

## Workflow

1. Capture the user request as the coordination brief.
2. Decide whether the work needs a mission or is a small follow-up.
3. Prefer an existing pipeline, governed actuator, or Kyberion MCP tool.
4. Change one thing and verify it immediately.
5. End with a review handoff when code, knowledge, or audit state changed.

Do not bypass tier boundaries, approval gates, or mission ownership.
